## 1. 네이버 쇼핑 검색 API 종료 대응 — 수동 큐레이션 방식 전환

**커밋**: `26f30ff` — `feat: 네이버 쇼핑 검색 API 종료 대응 — 수동 큐레이션 데이터 기반으로 전환`

### 무엇을 했는가

- `services/curated_product_service.py` 신규 추가 — MongoDB `curated_products` 컬렉션에서 상품 데이터를 조회
- `scripts/import_curated_products.py` 신규 추가 — CSV 파일을 읽어 MongoDB에 적재하는 스크립트
- `scripts/curated_products_template.csv` 신규 추가 — 14개 조합(제품 × 향)의 상품 데이터 템플릿
- `api/products.py` 수정 — `product_service` → `curated_product_service`로 교체, `requests` 관련 예외 처리 제거
- `database/mongodb.py` 수정 — `curated_products` 컬렉션 상수 및 접근 함수 추가
- `main.py` 수정 — `naver` 라우터 비활성화 (주석 처리 + 종료 사유 명시)
- `services/product_service.py` 수정 — 파일 상단에 미사용 안내 주석 추가 (참고용 보존)
- `docs/ROADMAP.md` 수정 — API 종료 반영, Phase 1 항목 갱신

### 왜 진행했는가

- 네이버 쇼핑 검색 API(shop.json)가 **2026-07-31부로 완전히 종료**되어, 기존 상품 검색 기능이 동작하지 않는 상태였음 (라우터 비활성화 후 `/naver/search`는 502 반환)
- 대체 API를 검토했으나 적합한 것이 없었음:
  - NAVER API HUB: 검색결과·통계용, 상품 데이터 구조 없음
  - 쿠팡파트너스 API: 어필리에이트 전용, 호출 제한 심함
  - 11번가 오픈API: 셀러 등록 필수
  - 크롤링: 법적 리스크
- 이 프로젝트는 product × scent × fragrance 조합이 **14개로 고정**되어 있어, 실시간 검색이 필수가 아님
- 따라서 **수동으로 큐레이션한 상품 데이터를 CSV로 관리**하고 MongoDB에 적재하는 방식이 가장 현실적이라고 판단

## 2. 프론트엔드 UI 개선 — 상품 카드 통일 및 CTA 동적 표시

**커밋**: `프론트엔드 UI 수정 상품 카드 크기 통일 및 판매처별 CTA 텍스트 동적 표시`

### 무엇을 했는가

#### `frontend/styles/style.css`
- `.product-grid`: `repeat(2, 1fr)` → `repeat(auto-fill, minmax(240px, 1fr))` + `justify-content: start`
- `.product-card__media`: `padding-top: 100%` → `aspect-ratio: 1 / 1`
- `.product-card__image`: `position: absolute` 제거, `display: block` 추가
- 반응형 `@media`에서 `.product-grid` 고정 컬럼 규칙 제거 (auto-fill이 자동 처리)

#### `frontend/js/shared.js`
- CTA 바 텍스트를 `"네이버에서 보기 →"` 하드코딩 → `mallName`에 따라 동적 생성
  - 네이버 스토어 → "네이버 스토어에서 보기 →"
  - 쿠팡 → "쿠팡에서 보기 →"
  - 값 없음 → "상품 보기 →"

### 왜 진행했는가

- CSV에 상품 데이터를 넣기 시작하면서 **이미지 카드 크기가 향마다 제각각**인 문제 발견
  - 원인: 이미지 원본 비율이 달라서 카드 높이가 불일치
  - 해결: `aspect-ratio: 1/1`로 모든 이미지 영역을 정사각형으로 고정
- 상품이 1개만 있을 때 카드가 **중앙에 배치**되는 문제
  - 해결: `justify-content: start`로 항상 왼쪽부터 정렬
- 기존에는 모든 판매처를 "네이버에서 보기"로 표시했는데, 쿠팡 등 **다른 판매처 데이터가 추가**되면서 실제 판매처에 맞게 표시할 필요가 생김

## 3. 큐레이션 상품 데이터 추가

**커밋**: `1ebbe20` — `바디워시 및 샴푸 데이터 수동 추가`

### 무엇을 했는가

- `backend/scripts/curated_products_template.csv`에 bodywash 전 향 데이터 수동 입력:
  - 복숭아, 자몽, 레몬, 망고, 딸기 (fruity 계열)
  - 샌달우드, 시더우드 (woody 계열)
- 각 상품의 title, image, lprice, mallName, link를 네이버 쇼핑/쿠팡에서 직접 수집

### 왜 진행했는가

- 수동 큐레이션 방식으로 전환했으므로 실제 상품 데이터를 채워야 서비스가 동작함
- 빈 템플릿 상태에서는 모든 페이지에서 "관련 상품이 없습니다"만 표시됨

### 데이터 입력 중 발견한 이슈

- 망고향 이미지 URL에 `?type=f140`(140px 썸네일)이 포함되어 다른 상품보다 이미지가 작고 흐릿하게 표시됨
  - `?type=o1000`(1000px 원본)으로 수정하여 해결
  - 앞으로 데이터 추가 시 이미지 URL의 `?type=` 값을 `o1000`으로 통일할 것
