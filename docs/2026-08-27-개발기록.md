## 네이버 쇼핑 API 상품 검색 오류 분석

### 현상

일부 향(fragrance) + 제품(product) 조합으로 검색 시 상품이 0건으로 나오거나 기대보다 적게 표시되는 문제가 있었습니다.

### 원인 분석

#### 1. 검색어 조합의 한계

현재 검색 쿼리 생성 방식 (`product_service.py:_build_queries`):

```python
# 예: "복숭아 샴푸", "로즈 바디워시" 형태로 생성
term = synonyms[0] if synonyms else fragrance["name"]
queries.append(f"{term} {product_keyword}")
```

- 향 동의어 중 **첫 번째 한국어 단어**만 사용하여 검색 → 네이버 API에서 해당 단어로 등록된 상품이 없으면 결과가 없음
- 예를 들어 "샌달우드 샴푸"로 검색하면 네이버에 "샌달우드"가 포함된 샴푸 상품이 거의 없어 결과가 0건

#### 2. 엄격한 필터링 로직

검색 결과를 가져온 후 `_filter_items()`에서 **이중 필터링**을 적용:

```python
# title에 향 동의어 AND 제품 키워드가 모두 포함되어야 통과
any(s in title for s in synonyms) and any(k in title for k in product_keywords)
```

- 네이버 API가 관련 상품을 반환하더라도, 상품 제목에 향 이름이나 제품 카테고리 키워드가 **정확히 포함**되지 않으면 필터에서 제외됨
- 예: "우디향 샴푸"로 검색 → 결과에 "씨더우드"는 있지만 제목에 "시더우드"가 아닌 "cedar"로만 적혀 있으면 불일치 발생

#### 3. 네이버 API 자체 제한

- **일일 호출 한도**: 네이버 오픈 API는 일일 25,000건 호출 제한이 있음. 다수의 향 × 제품 조합을 병렬 호출하면 한도 초과 가능
- **429 Rate Limit**: 짧은 시간에 과다 요청 시 `429 Too Many Requests` 응답 → 현재 코드에서 에러 핸들링은 되어 있으나 (`api/naver.py:27-31`, `api/products.py:35-36`), 실패한 요청의 결과는 빈 배열로 처리됨
- **타임아웃**: `NAVER_TIMEOUT_SECONDS = 5`로 설정되어 있어 네트워크 지연 시 타임아웃 발생 가능
- **검색 API 특성**: 네이버 쇼핑 검색은 상품 **제목 기반** 매칭이므로, 향기 관련 키워드가 상품명에 포함되지 않은 상품은 애초에 API 결과에 포함되지 않음

#### 4. 캐시 관련 이슈

- 캐시가 한 번 비어있는 상태(`items: []`)로 저장되면, 이후 요청에서 API를 다시 호출하지 않고 빈 캐시를 그대로 반환
- MongoDB의 TTL 인덱스로 캐시 만료를 관리하고 있지만, 만료 전까지는 빈 결과가 유지됨

### 정리

| 원인 | 영향 | 현재 상태 |
|------|------|----------|
| 단일 동의어로만 검색 | 검색 커버리지 부족 | `_build_queries`에서 첫 번째 동의어만 사용 |
| AND 조건 필터링 | 유효 상품 과도 제거 | `_filter_items`의 이중 조건 |
| API 호출 한도 초과 | 일부 향 검색 실패 | 병렬 호출 시 429 에러 가능 |
| 빈 결과 캐시 | 재시도 불가 | 캐시 TTL까지 빈 결과 유지 |
| 상품명에 향 키워드 미포함 | API 자체 결과 부재 | 네이버 검색 엔진 특성상 불가피 |
