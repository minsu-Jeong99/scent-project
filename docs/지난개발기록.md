### 📌 프로젝트 개요

- 제품(샴푸, 바디워시 등)을 향기로 분류하여 사용자에게 맞춤 추천을 제공하는 정적 웹사이트를 개발했습니다.
- HTML + CSS + JS 기반 정적 웹 구조에서 FastAPI 기반 백엔드와 연동하여 향기 분류, 상품 검색, 가격 정렬 기능을 포함했습니다.
- 실제 네이버 쇼핑 API를 통해 각 향기와 연관된 실시간 쇼핑 데이터를 수집 및 표시했습니다.

### 🛠️ 사용 기술 스택

- **Frontend**
    - HTML + CSS + JavaScript (정적 버전)
- **Backend**
    - FastAPI (Python 비동기 REST API)
    - MongoDB (향기 및 제품 정보 저장)
- **API 연동**
    - 네이버 쇼핑 검색 API (`/naver/search` 엔드포인트로 연동)

### ⚙️ 주요 기술 구현 설명

- **병렬 API 요청 최적화**
    
    `Promise.all()`을 사용해 `fragrance` 목록에 대해 네이버 API를 동시에 호출. 응답 속도 향상 및 로딩 개선에 기여.
    
- **검색어 필터링**
    
    `item.title.toLowerCase().includes(product.toLowerCase())` 조건으로 불필요한 상품 제거. 향기 연관성 높은 제품만 사용자에게 노출.
    
- **한글-영어 키워드 대응**
    
    `"샴푸" → "shampoo"`, `"자몽향" → "grapefruit"`과 같이 `TRANSLATION` 딕셔너리를 정의하여 다양한 조합의 쿼리를 자동 생성.
    

### 🧪 개발 중 해결한 문제

- ❌ **한글 검색어가 API에서 정확히 매칭되지 않는 문제**
    
    → 영어 번역 쿼리를 함께 사용하여 coverage 확장
    
- ❌ **제품 카테고리에 다른 제품이 섞여 출력되는 문제**
    
    → 검색 결과 필터링 로직으로 해결 (`includes(product)`)
    
- 제품(샴푸, 바디워시 등)을 향기로 분류하여 사용자에게 맞춤 추천을 제공하는 정적 웹사이트를 개발했습니다.
- HTML + CSS + JS 기반 정적 웹 구조에서 FastAPI 기반 백엔드와 연동하여 향기 분류, 상품 검색, 가격 정렬 기능을 포함했습니다.
- 실제 네이버 쇼핑 API를 통해 각 향기와 연관된 실시간 쇼핑 데이터를 수집 및 표시했습니다.

### 🚀 배포 및 운영 경험

- **백엔드 배포**:
    
    AWS EC2에 FastAPI 서버를 배포하고, **Nginx + Certbot** 조합을 통해 HTTPS 환경을 구성함.
    
    퍼블릭 IP가 아닌 **도메인(scent.o-r.kr)** 기반 접근이 가능하도록 설정함.
    
- **SSL 인증서 적용**:
    
    `certbot`을 사용해 Let’s Encrypt 인증서를 발급하고, Nginx 서버 블록을 통해 **HTTP → HTTPS 자동 리디렉션**을 적용.
    
- **CORS 정책 설정**:
    
    Vercel에 배포된 정적 프론트엔드와의 통신을 위해 FastAPI에 **CORS Middleware** 설정을 추가하여 브라우저 보안 정책 충돌을 방지함.

### 🛠️ 백엔드 라우팅 및 데이터 설계

- **RESTful API 설계**
    
    `/fragrances`, `/fragrances/{product}`, `/products/{product_name}/{scent}` 등 **계층적 API 구조**로 정리하여 유지보수 용이성을 확보.
    
- **MongoDB 구조 최적화**
    
    scent, fragrance, product의 관계를 컬렉션 내 문서 구조로 명확하게 구분하여 불필요한 중복을 줄이고 검색 속도를 개선.

### 🔐 보안 및 안정성 대응

- **Mixed Content 오류 해결**
    
    HTTPS 환경에서 HTTP API 요청 시 발생하는 **Mixed Content 오류**를 `https://scent.o-r.kr`로 API 호출 경로를 통일하여 해결.
    
- **자동 봇 및 스캐너 요청 차단**
    
    `.env`, `/actuator`, `/admin` 등 자동화된 비정상 요청을 감지하고 로깅하여 보안 사고를 사전 차단.
    
- **FastAPI 유지 프로세스**
    
    SSH 세션 종료 이후에도 서버가 자동 종료되지 않도록 `gunicorn`, `nohup`, `tmux` 등의 **프로세스 관리 전략**을 고민함.

### 📦 기타 개선 포인트

- **가격 정렬 기능**
    
    버튼을 누르면 오름차순/내림차순 정렬을 토글하며 상품 정보를 사용자에게 더 직관적으로 제공.

    `product.html?product=shampoo` → `scent.html?scent=floral` → `fragrance.html?fragrance=rose`처럼 **쿼리 기반 이동 구조**로 페이지 전환 설계.
